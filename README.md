# Portfólio — Heitor Gomes

Site estático feito com HTML, CSS e JavaScript, publicado pelo GitHub Pages.
Não precisa instalar dependências nem configurar um servidor.

## Acessar o site

https://heitorgomess.github.io/portfolio-heitor-gomes/

## Como atualizar

1. Edite `index.html`, `styles.css` ou `script.js`.
2. Salve e envie as alterações para a branch `main`:

   ```powershell
   git add .
   git commit -m "Atualiza o portfólio"
   git push
   ```

3. Aguarde a publicação do GitHub Pages. As alterações podem levar alguns
   minutos para aparecer no endereço do site.

## Configuração da hospedagem

No repositório do GitHub, acesse **Settings → Pages**. A publicação deve estar
configurada para a branch `main`, usando a pasta `/(root)`. Assim, o GitHub
serve diretamente os arquivos do site, sem etapa de build.

## Próximos ajustes

Antes de divulgar, atualize os links provisórios de WhatsApp, e-mail e redes
sociais no `index.html`. O endereço canônico já aponta para o GitHub Pages;
se um domínio próprio for configurado mais tarde, atualize-o junto com a
configuração de domínio em **Settings → Pages**.
